隐私政策

生效日期：2026年11月6日
适用扩展：临时聊天本地宝 - ChatGPT Local Vault

本扩展不会把用户的 ChatGPT 对话内容发送给开发者。聊天记录保存在用户自己的 Chrome 本地存储中。

1. 概述

临时聊天本地宝是一款在用户设备本地保存和管理 ChatGPT 临时聊天记录的 Chrome 扩展。本扩展由 Donnyda 提供。

2. 扩展处理的数据

  • 当前 ChatGPT 页面中可见的用户提问和回答。
  • ChatGPT 会话 ID、临时聊天状态和页面地址。
  • 用户设置的标题、置顶状态和扩展偏好。
  • 本地会话数量、消息数量和存储占用。

3. 数据用途

数据仅用于本地保存、搜索和显示聊天记录；导出用户主动选择的 Markdown 或 JSON 备份；在用户主动操作时将历史上下文填入 ChatGPT 输入框；以及管理本地记录。

4. 数据存储与保留

  • 聊天数据保存在 chrome.storage.local。
  • 数据不会通过本扩展上传至开发者服务器。
  • 用户可以删除单条记录、清空全部记录或卸载扩展。
  • 用户导出的文件由用户自行管理。

5. 数据共享与出售

本扩展不出售用户数据，不向广告商共享聊天内容，不将数据用于广告、用户画像或信用评估，也不包含第三方分析或广告 SDK。

6. 网站访问权限

本扩展仅请求访问 https://chatgpt.com/* 和兼容旧域名 https://chat.openai.com/*。权限用于读取当前可见聊天、识别临时聊天、显示本地界面，以及执行用户主动触发的上下文续接。

7. 数据安全

扩展采用 Manifest V3，不执行远程代码。用户应保护设备和 Chrome 浏览器账户，并谨慎管理主动导出的备份文件。

8. 第三方服务

本扩展是独立开发的第三方工具，不隶属于 OpenAI，也未获得 OpenAI 官方背书。用户使用 ChatGPT 时仍受 OpenAI 自身条款和隐私政策约束。

9. 政策更新

如果数据处理方式发生实质变化，我们会同步更新本政策和 Chrome Web Store 隐私披露，并在适用时向用户提供明显提示。
